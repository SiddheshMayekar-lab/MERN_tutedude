# Student Records Web Page

## Overview

This project displays student records using HTML and JavaScript. It shows student details in card format and allows searching students by name.

## Features

* Display student details (name, marks, class, address)
* Show records in card format
* Search students by name
* Real-time filtering using search box

## Output

Student cards displayed on screen
Search box filters students as you type
