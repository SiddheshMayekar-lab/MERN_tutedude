# Laundry Mart – Responsive Landing Page  
CSS Flexbox & Responsive Design Project

## Project Overview

This project implements a modern and fully responsive landing page for Laundry Mart using HTML and CSS.

The layout is structured using CSS Flexbox to create a clean navigation bar and a professional hero section with balanced spacing and proper alignment. The design adapts seamlessly across Desktop, Tablet, and Mobile devices using media queries.

The primary objective of this project is to practice Flexbox layout structuring, responsive design techniques, and professional UI styling without using any CSS frameworks.

---

## Features Implemented

### 1. Responsive Navigation Bar
- Built using `display: flex`
- Logo with Font Awesome icon
- Navigation links (Home, Services, About, Contact)
- Rounded bordered user profile container
- Circular avatar displaying user initial
- Full name displayed beside avatar
- Navigation links hidden on mobile screens

### 2. Professional Hero Section
- Two-column layout (Text + Image) on Desktop
- Vertically centered using Flexbox
- Gradient background styling
- Clean typography hierarchy
- Balanced spacing between elements
- Proper image scaling with shadow effect

### 3. Call-to-Action Buttons
- Rounded button design
- Icon support using Font Awesome
- Hover effects with smooth transitions
- Full-width stacked buttons on mobile

### 4. Feature Highlights
- Free Pickup
- Premium Care
- 24 Hour Delivery
- Horizontal alignment on Desktop
- Vertical stacking on smaller screens

### 5. Responsive Design Implementation
- Desktop layout with side-by-side alignment
- Tablet layout switches to column using `flex-direction: column`
- Mobile layout optimized with centered content
- Media queries used at:
  - `max-width: 992px`
  - `max-width: 600px`

---

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Media Queries
- Font Awesome (CDN)
- Viewport height calculation (`calc(100vh - navbar height)`)

No frameworks were used.  
No inline CSS was used.  
All styling is written in a separate CSS file.

4. Click “Open with Live Server”.
