# CSS Selectors Task – Task 3

## Overview
This project demonstrates the use of different CSS selectors and specificity rules.  
The task was completed strictly following all assignment instructions without using inline CSS or Bootstrap.

It also includes a small CSS-only surprise button created using advanced selector techniques.

---

## Concepts Used

- Element Selector
- Class Selector
- ID Selector
- Descendant Selector
- CSS Specificity (ID > Class > Element)
- Pseudo-class (:checked)
- Hover Effects
- Proper Separation of HTML and CSS

---

## Task Requirements Implemented

1. Created index.html and style.css files.
2. Linked external CSS properly.
3. Applied background color to body.
4. Created 3 headings with class "head".
5. Styled all headings with class selector.
6. Styled second heading using ID selector.
7. Demonstrated CSS specificity (ID overriding class).
8. Styled paragraph elements using element selector.
9. Customized second paragraph using ID selector.
10. Styled specific word using span and class selector.
11. Created two lists and styled "here" text without using inline CSS or id/class.

---

## Surprise Feature

A small surprise button is included at the bottom of the page.

- Built using only HTML and CSS
- No JavaScript used
- Uses :checked pseudo-class technique
- Displays a thank-you message when clicked
