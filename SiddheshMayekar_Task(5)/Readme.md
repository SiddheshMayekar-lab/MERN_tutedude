# Laundry Wallah / Laundry Mart  
Hero Section Web Application

## Project Overview

This project implements the Hero Section of a laundry service web application.  
The objective of this assignment is to design and structure a clean layout using HTML and CSS while following specific constraints such as avoiding Flexbox and using viewport units.

The application contains a navigation bar and a full-screen hero section structured using display properties like inline and inline-block.

---

## Features Implemented

### 1. Navbar
- Logo displayed on the left
- Navigation links: Home, Services, About Us, Contact Us
- User name displayed on the right
- Implemented using `display: inline`
- Flexbox is not used

### 2. Hero Section
- Full screen height using `100vh`
- Two div layout:
  - Left Div:
    - Heading
    - Description paragraph
    - "Book a Service Today" button
  - Right Div:
    - Laundry related image
- Layout built using `inline-block`
- No scrolling within the hero section

---

## Technologies Used

- HTML5
- CSS3
- Viewport Units (vh)
- Display Properties (inline, inline-block)

## Assignment Constraints Followed

- Flexbox is not used.
- Navbar implemented using `display: inline`.
- Hero section contains exactly two divs.
- Full screen layout achieved using `100vh`.
- Clean and structured code format maintained.
