# JavaScript Number Operations Program
This program performs multiple mathematical operations on a given number using JavaScript.
It demonstrates basic programming concepts such as loops, condition checks, and arithmetic operations.

The program works with a number (num) and performs different calculations including digit operations, multiplication tables, number property checks, and factor generation.
