# OmniFood Landing Page

## Project Overview

This is a responsive food delivery landing page built using HTML and CSS.
It includes sections like Hero, How it Works, Cities, Testimonials, Pricing, and Footer.

## How to Run

Just open index.html in any browser.

## Responsive Breakpoints Used

- Desktop: above 1200px
- Tablet: below 834px
- Mobile: below 390px

## Folder Structure

- index.html
- style.css
- script.js
- assets (optional images)

## Notes

- Layout built using flexbox
- Media queries added step by step
- Simple JS added for navbar scroll effect
