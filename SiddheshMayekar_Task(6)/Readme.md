# Laundry Mart Login Page  
CSS Flexbox Assignment

## Project Overview

This project implements a visually structured Login Page for Laundry Mart using HTML and CSS.  
The layout follows a split-screen design with an image on the left and a login form on the right.

The primary objective of this task is to practice and apply CSS Flexbox properties for layout alignment and centering.

---

## Features Implemented

### 1. Full Screen Container
- Container height set to `100vh`
- Layout structured using `display: flex`
- Content centered using `justify-content` and `align-items`
- No margin or padding used for centering

### 2. Split Layout Design
- Left Section:
  - Laundry-related image
  - Gradient background
- Right Section:
  - Login form
  - Centered vertically and horizontally using Flexbox

### 3. Login Form Section
- Heading: "Hello Again!"
- Subheading message
- Email input field with placeholder
- Password input field with placeholder
- Styled Login button with hover effect

### 4. Responsive Scaling
- Optimized sizing so layout looks balanced at 100% zoom
- Increased font sizes, input height, and button size for better visual proportion
