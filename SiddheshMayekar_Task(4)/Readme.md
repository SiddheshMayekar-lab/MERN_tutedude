# Task 3 – CSS Units, Box Model, and Fonts

## Project Overview
This project demonstrates the implementation of CSS viewport units, proper box model handling, and font styling. The layout has been designed according to the given requirements, ensuring equal spacing from left and right sides of the screen and balanced spacing from the top and bottom. The page is structured to prevent scrolling and follows all specified constraints.

## Technologies Used
- HTML5
- CSS3

## Concepts Implemented
- Viewport units (vh and vw)
- Proper use of box-sizing (border-box)
- Equal horizontal spacing of 25% from left and right
- Vertical spacing of 10% from top and bottom
- External stylesheet linking
- Page layout without scroll
- No use of Flexbox
- No use of overflow: hidden
- No use of position: relative or position: absolute


## How to Run the Project
1. Download or clone the repository.
2. Open the project folder.
3. Ensure both `index.html` and `style.css` are in the same directory.
4. Open `index.html` in any modern web browser.

## Outcome
The project successfully demonstrates the use of viewport units and box model principles while maintaining a structured and responsive layout as per the assignment guidelines.
