# Laundry Mart Animation Task

This project is a small practice task to learn CSS animations.

In the hero section of the webpage, the image moves slightly in an orbit motion and also stretches and squeezes at different points of the animation. This effect is created using CSS @keyframes and transform properties like translate() and scale().

Files included in the project:

index.html – webpage structure  
style.css – styling and animation  
images folder – contains the hero image  

How to run the project:

1. Download or unzip the project folder
2. Open the folder in any editor like VS Code
3. Open the file index.html in a web browser

The animation will start automatically when the page loads.

This task helped me understand how CSS keyframe animations work and how transforms can be used to move and scale elements.
