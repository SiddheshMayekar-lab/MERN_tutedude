## About This Task

In this assignment, I had to fix the responsive issues of the Laundry Services webpage that we created earlier. The desktop version was working fine, but when I checked it on tablet and mobile screen sizes, the layout was breaking.

The main objective was to properly use Flexbox and media queries to make the page responsive without hiding important content.

After getting feedback, I understood that my earlier CSS looked too polished and complex for a beginner-level assignment. Even though the layout was working, it did not clearly show my actual understanding of Flexbox.

I want to honestly mention that I did take some help from AI while building the previous version. I now understand that depending too much on it reduces the learning value of the task. This assignment is meant to test my understanding, not perfection.

So I rewrote the CSS in a simpler and clearer way so that it truly reflects what I understand at this stage.

## What I Learned

- How display: flex works by default in row direction.
- The difference between justify-content and align-items.
- How flex-direction: column helps stack elements vertically.
- How to reduce text size and image size for smaller screens.
- Why we hide navigation links in mobile view to save space.
- How stacking buttons vertically improves mobile usability.
- How media queries override styles at different screen widths.

---

## What I Found Difficult

- Managing spacing when layout changes from row to column.
- Making sure the hero section looks balanced on all screen sizes.
- Deciding proper font sizes for tablet and mobile.
- Understanding how media queries interact with existing styles.

Initially, I focused too much on design polish instead of layout logic. This feedback helped me correct that.

---

## Improvements After Feedback

After reviewing the feedback, I made the following changes:

- Removed advanced styling like gradients and complex effects.
- Simplified the CSS structure.
- Added CSS variables for breakpoints (992px and 600px).
- Removed display: none from feature sections and stacked them instead.
- Made both buttons visible and full-width in mobile view.
- Added meaningful comments explaining layout decisions.
- Tested the layout properly at different screen sizes.

## Testing

I tested the page using Chrome DevTools at:

- 1200px (Desktop)
- 992px (Tablet)
- 600px (Mobile)

I confirmed that:

- Navbar adapts correctly.
- Hero section stacks properly.
- Text and image sizes reduce appropriately.
- No important content disappears.
- Layout does not break.

## Final Thoughts

This assignment helped me better understand responsive design using Flexbox and media queries. I now feel more confident handling layout changes across screen sizes.

Most importantly, I learned that writing simple and clear code that reflects my own understanding is more valuable than trying to make it look overly professional.

This task strengthened my foundation in responsive design.
