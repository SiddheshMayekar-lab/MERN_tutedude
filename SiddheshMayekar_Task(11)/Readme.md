## Project Overview

**Thala 7 Sneaker Store** is a multi-page front-end project built using **HTML5 and CSS3**.
The objective of this project is to demonstrate the use of **CSS Flexbox for layout design** while creating a simple e-commerce style website.

The website includes multiple pages such as a landing page, product page, shopping cart, and checkout page. Font Awesome icons are used for UI elements such as cart, search, and payment methods.

This project focuses purely on **frontend structure and layout**, without any backend or database functionality.

---

## Pages Included

### 1. Landing Page (index.html)

The landing page introduces the sneaker store and highlights the product.

Features:

* Navigation bar with menu links
* Brand logo (Thala 7)
* Hero section with product image and call-to-action button
* Service highlights such as reviews and ratings

---

### 2. Product Page (product.html)

This page displays the main sneaker product.

Features:

* Product image display
* Product description
* Price and quantity selector
* Add to Cart button
* Horizontal product image gallery

---

### 3. Shopping Cart Page (cart.html)

This page shows the items added to the cart.

Features:

* Cart table showing product, quantity, and price
* Remove product icon using Font Awesome
* Coupon input field
* Order summary with subtotal, taxes, discount, and total
* Pay Now button

---

### 4. Checkout / Payment Page (payment.html)

The checkout page allows users to enter payment information.

Features:

* Email input field
* Payment method selection (Card, Crypto, Bank)
* Card details form
* Country and ZIP inputs
* Order summary
* Payment icons (Visa, Mastercard, Amex, PayPal)
