# React Shoe Store

This project is a simple React application that simulates an online shoe store. It allows users to view a list of shoes and manage a basic shopping cart using React's useState hook.

## Features

* Displays a list of available shoes with name, price, and image
* Add items to the cart
* Remove items or decrease quantity
* Calculates and displays total cart value

## Technologies Used

* React (useState)
* Vite
* CSS

## Project Structure

* `src/App.jsx` – Contains main application logic and UI
* `src/main.jsx` – Entry point of the application
* `src/App.css` – Styles for layout and components
