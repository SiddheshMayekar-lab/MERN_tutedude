# Even or Odd Number Checker
Description
This JavaScript program checks whether a number is even or odd using an if-else statement. Multiple variables are used to store numbers, and the result is printed in the console.

## Logic Used

The modulus operator '%' is used to check the remainder.
If a number divided by 2 gives remainder 0, it is Even.
Otherwise, the number is Odd.
