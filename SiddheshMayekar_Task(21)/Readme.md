# OmniFood - Healthy Food Delivery Landing Page

A responsive, single-page landing website for a healthy food delivery brand built with pure HTML and CSS.

## Project Overview

OmniFood is a modern food delivery service that provides healthy, delicious meals delivered right to your doorstep. This landing page showcases the brand's services, features, pricing plans, and customer testimonials.

### Features

- **Responsive Design**: Fully responsive layout that works on desktop, tablet, and mobile devices
- **Pure CSS**: Built with only HTML and CSS (no Bootstrap or Tailwind)
- **Minimal JavaScript**: Only used for the mobile hamburger menu toggle
- **Modern UI**: Clean, professional design with smooth transitions and hover effects
- **6 Main Sections**:
  1. Header with Navigation + Hero Banner
  2. How It Works (3-step process)
  3. Our Cities (4 city cards)
  4. Testimonials (customer reviews)
  5. Pricing Plans (3 tiers)
  6. Footer (links and social icons)

## How to Run

Simply open the `index.html` file in any modern web browser:

```bash
# Option 1: Double-click index.html
# Option 2: Right-click index.html and select "Open with" your browser
# Option 3: Use a local server (optional)
```
