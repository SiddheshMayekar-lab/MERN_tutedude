# Laundry Service Web App

## Features
- Navbar with Home, Services, About, Contact
- Hero section with "Book a Service" button
- Services list with add/remove functionality
- Booking section with cart and total amount
- User form (name, email, phone)
- Email confirmation on booking
- Service overview stats
- Newsletter subscription section
- Footer with links and social icons

## Functionality
- Add/remove services dynamically
- Calculate total amount
- Scroll to booking section
- Send booking details via EmailJS
- Show confirmation message after booking
